# Brain Dump

A lightweight place to capture ideas before they become projects.

## How it works

- **One idea = one GitHub Issue.**
- Capture the idea quickly; it does not need to be polished.
- The issue creation time is the original capture timestamp.
- Use the linked **Brain Dump** GitHub Project to view ideas by date on a Roadmap.
- Ideas are not requirements and should not be implemented automatically.

## Idea lifecycle

`Inbox → Exploring → Promising → Project → Archived`

An idea can stay in Inbox forever. Moving it forward is a deliberate decision.

## Dates

- **Created at** — when the idea was first captured (GitHub issue timestamp).
- **Captured** — date used by the Project Roadmap.
- **Review on** — optional future date to revisit an idea.

## Rule for AI agents

Content in this repository is brainstorming material. Do not treat an idea as an approved requirement, roadmap item, or implementation task unless it is explicitly promoted to a project/spec.
